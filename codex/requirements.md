# 중고거래 플랫폼 요구사항 분석

## 1. 서비스 개요

| 항목 | 내용 |
| --- | --- |
| 서비스명 | 한국어 기반 중고거래 플랫폼 |
| 목적 | 사용자가 상품 등록, 거래, 소통, 신고/차단, 송금까지 수행할 수 있는 웹서비스 |
| 주요 사용자 | 비회원, 일반 회원, 판매자, 구매자, 관리자 |
| 현재 목표 | MVP 안정화 + 미구현 핵심 기능 우선 구현 |

## 3. 남은 우선 과제

| 우선순위 | 항목 | 이유 |
| --- | --- | --- |
| 1 | 검색 UI 고도화 | 백엔드 필터는 이미 존재 |
| 2 | 관리자 상세 액션 확장 | 현재는 조회/숨김/삭제/잔액조정 중심 |
| 3 | 송금 후속 정책 | 환불, 취소, 에스크로 등은 아직 미포함 |

## 4. 비범위 / 후순위

- 외부 PG 연동
- 실시간 WebSocket 채팅
- 추천 알고리즘
- 인기 검색어/자동완성 고도화
- 에스크로/정산 시스템
